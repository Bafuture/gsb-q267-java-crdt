## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们多节点各自更新同一份计数与集合，网络恢复后要靠数据本身收敛，不依赖中心协调。请从零实现 CRDT 计数器与集合组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 实现 G-Counter（只增）与 PN-Counter（可增减），合并操作用逐副本取最大值；2) 实现 OR-Set（可增删集合）：元素的增与删带唯一标记，合并后不得丢失未被删除的新增；3) 收敛性验证：任意副本以任意顺序交换消息，有限轮后所有副本状态一致，需有测试证明并给出轮次；4) 支持乱序与重复消息：重复合并与乱序合并结果必须与按序合并一致（幂等与交换律）；5) 支持状态压缩：把多次增量合并成紧凑状态，压缩后合并不改变结果；6) 支持并发增删同一元素的语义说明（例如并发删除不覆盖并发新增）；7) 提供统计：各副本状态大小、合并次数与收敛轮次；8) 测试覆盖两种计数器、OR-Set 增删、收敛性、乱序重复合并、状态压缩与并发语义；`mvn -q verify` 一条命令跑通。
